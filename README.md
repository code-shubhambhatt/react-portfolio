# React Portfolio

A personal portfolio website built with React and Vite — designed to showcase projects, skills and contact information in a clean, responsive way.

## 🚀 Features

* Responsive layout — works across mobile, tablet, and desktop screens.
* Clean structure using React + Vite for fast development and build.
* Static asset support via an `assets/` folder (e.g. images, icons) for easy customization.
* Simple folder structure to help you locate components, assets, and public files easily.

> Note: This project does **not** include any backend/API — it’s a static portfolio built with React.

## 🛠️ Tech Stack

* React (frontend)
* Vite (build tool & dev server)
* Plain CSS / static assets (CSS + HTML + JS)
* Static asset folder for images, icons etc.

## 📁 Folder Structure

```
/
├── assets/             # Static images, icons and other media
├── public/             # Public static files (served as-is)
│   └── index.html      # HTML template
├── src/                # Source code (React components / pages / logic)
│   └── …               # (Your custom structure inside src)
├── package.json        # Project dependencies & scripts
├── package-lock.json   # Lockfile for dependencies
├── vite.config.js      # Vite configuration
└── README.md           # This file
```

## 💡 Installation & Setup

1. Clone the repo:

   ```bash
   git clone https://github.com/code-shubhambhatt/react-portfolio.git
   cd react-portfolio
   ```
2. Install dependencies:

   ```bash
   npm install
   ```

## ▶️ Run the Project (Development)

```bash
npm run dev
```

Then open `http://localhost:5173` (or the port Vite shows in console) in your browser to view your portfolio locally.

## 🛠️ Build for Production

```bash
npm run build
```

This will generate a production-ready build (static files) — suitable for deployment via GitHub Pages, Vercel, Netlify, or any static-hosting service.
